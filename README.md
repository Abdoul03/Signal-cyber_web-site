# SIGNAL CYBER

Application React côté client pour signaler et accompagner les victimes de violences numériques au Mali.

## Development

Le projet utilise Vite et nécessite Node.js ainsi que npm — [installer Node.js avec nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Technologies

- React
- Vite
- TanStack Router
- TypeScript
- Tailwind CSS
